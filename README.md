# Smart Exam Platform

面向教师与学生的智能在线题库与组卷系统。项目采用前后端分离的 Java Web 架构，由一人完成；设计、开发与测试时间到 9 月 5 日结束，9 月 6 日为集成测试、系统实施与回报。

## 核心流程

教师维护题库 → 创建并发布试卷 → 学生在线答题 → 系统批改客观题 → 教师批阅主观题 → 公布并查询成绩。

## 功能范围

- 管理员：用户管理和账号状态维护，以及在系统设置页修改运行参数（六项白名单，保存即生效）
- 教师：题库管理（五种题型、关键词标签、启用停用、批量导入）、手动组卷与**规则自动组卷**、**试卷导出**、考试发布、完整答卷查看、主观题阅卷、成绩排名统计，以及统计分析（题库分布、成绩分布、逐题正确率）和系统设置
- 学生：参加考试、提交答卷、恢复未交卷答案、查看本人名次和已公布答卷、**错题本与错题重练**
- 增强功能（6 项，已全部实现）：AI 辅助出题、规则自动组卷、错题本与错题重练、统计分析图表、题库批量导入与试卷导出、答题自动保存与恢复。各项的用法见下文「本机启动」后的小节，设计取舍见 [`docs/project-report.md`](docs/project-report.md) 3.6

完整范围与排期见 [`plan.md`](plan.md)。

## 本机启动

要求安装 Java 21 或更高版本、Maven 3.9、Node.js 24 LTS 和 MySQL 8.4。Docker 不是必需项。

在仓库根目录执行一键初始化。脚本生成本地 `.env`、初始化数据库、安装依赖并验证两端：

```bash
./scripts/init-local.sh
```

脚本会提示输入 MySQL 管理员密码且不会保存该密码。初始化后启动后端：

```bash
set -a
source .env
set +a
mvn -f backend/pom.xml spring-boot:run
```

另开终端启动前端：

```bash
npm --prefix frontend run dev
```

访问前端 `http://localhost:5173`；后端健康检查为 `http://localhost:8080/api/health`。自定义数据库配置参照 `.env.example`，不要提交真实密码。

### AI 辅助出题（可选）

不配置也能正常使用系统，只是「题库管理 → AI 出题」会提示未配置。要启用就在 `.env` 里填四个变量：

| 变量 | 说明 |
|---|---|
| `AI_PROTOCOL` | `openai` 或 `anthropic` |
| `AI_BASE_URL` | `openai` 时带到版本段（如 `https://api.deepseek.com/v1`）；`anthropic` 时只到域名 |
| `AI_MODEL` | 模型名，直接透传给服务商 |
| `AI_API_KEY` | 密钥，只由后端读取，不下发浏览器 |

换服务商（DeepSeek、通义、Kimi、本地 vLLM/Ollama、Anthropic）只改这四个变量，不改代码。AI 只生成草稿，教师确认后仍走普通的题目新增接口保存。

### 题库批量导入

「题库管理 → 导入题库」支持粘贴表格或选择 CSV/TSV 文件，无需任何配置。弹窗里可以下载模板，模板由后端生成，五行示例覆盖五种题型。

流程固定为**先预览、再确认**：预览调的是同一个接口（`dryRun=true`），服务端不写任何数据，逐行告诉你「可导入 / 跳过 / 失败」以及失败原因和原文行号；没预览过不允许导入。

| 列 | 必填 | 说明 |
|---|:--:|---|
| 题型 | 是 | 单选题 / 多选题 / 判断题 / 简答题 / 编程题 |
| 题干 | 是 | 含逗号时整格用英文双引号包起来 |
| 知识点 | 是 | 按名称匹配，**必须已存在**，不会自动创建 |
| 标准答案 | 是 | 选择题写 `A` 或 `AB`；判断题写 正确 / 错误；主观题写参考答案 |
| 难度 | 否 | 易 / 中 / 难，留空按「中」 |
| 分值 | 否 | 留空按 10 分，最多一位小数 |
| 选项 | 选择题必填 | 一格内用竖线分隔，如 `A. 甲` \| `B. 乙`；不写选项号时按顺序补 A、B、C… |
| 解析 / 标签 | 否 | 标签用英文逗号分隔 |

单次行数上限默认 200 行（可在系统设置里调整）。导入的题目走与手工出题**完全相同**的业务校验，逐行独立成败（某行失败不影响其他行），题干与题库中已有题目重复时跳过（判重也可在系统设置里关掉）。Excel 请另存为「CSV UTF-8」，否则中文会读成乱码。

### 规则自动组卷

「组卷管理 → 自动组卷」按规则抽题：每条规则给出题型、难度、知识点（都可留「不限」）、抽几道和每道几分，可以加多条规则。

**本功能只生成方案，不直接保存试卷**：抽中的题目填进组卷页右侧，微调后仍点「保存草稿」。这样「分值合计等于总分」「题目属于本人」「题目处于启用状态」这些校验只有一处实现——与「AI 只出草稿」是同一条标准。反复点「换一批」会重新随机；题目不够时直接报错并点明是第几条规则、缺多少，不会悄悄少抽几道。

### 试卷导出

「组卷管理 → 我的试卷 → 导出」有两种格式，用途不同：

| 格式 | 用途 |
|---|---|
| Markdown | 可打印的卷子。默认**不含答案**，可直接发给学生；勾「含参考答案与解析」后在卷末附答案页 |
| CSV | 题目交换文件。列名与顺序等于**题库导入模板**，因此导出的文件可以原样喂回「导入题库」，把一份试卷的题目搬进另一位教师的题库或另一套环境。导入要求「标准答案」必填，所以 CSV 必然含答案 |

弹窗里直接显示要下载的正文，改任何选项都会立刻重新生成——「含答案」这个开关必须眼见为实。导出内容取自**试卷快照**，与当时发布的卷子完全一致。

### 错题本与错题重练

学生端第三个页签。**只收录已公布成绩考试里未得满分的题目**（未作答、答错、主观题部分得分都算），成绩公布前一个字都不会出现。

- **复习**：展开可看本人完整作答、参考答案、解析和教师评语；
- **重练**：只取可自动判分的客观题，练习界面**不下发标准答案**（否则就是抄答案），提交后即时判分并给出正确答案与解析。判分复用交卷时的同一套规则；
- **不改成绩**：练习记录写在独立的表里，答卷分数、名次一个字都不动。练对之后错题仍留在错题本里，只标记为「已掌握」。

### 系统设置（管理员可编辑）

「系统设置」上半部分是六项可修改参数：及格线百分比、令牌有效期、单次导入行数上限、导入是否跳过重复题干、自动组卷抽题上限、错题重练每组题数。**只有管理员能改，教师只读**；保存后立即生效，不需要重启。

存储模型是「环境变量是默认值、`system_setting` 表是覆盖层」，因此每一项都同时显示当前值、默认值和来源，「恢复默认」就是删掉覆盖行。

下半部分只读，且刻意不开放编辑：数据库连接与 JWT 密钥改了会让系统整体不可用；AI 密钥不能出现在浏览器里，AI 地址与协议一旦可编辑就等于把「后端向哪个地址发请求」做成了输入框；自动交卷扫描间隔与 AI 读超时在启动时就固化进了调度触发器和 HTTP 客户端，界面上改了也不会生效。
